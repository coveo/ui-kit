Ship an Agent Skill at `dist/skills/coveo-atomic`, generated from the custom elements manifest and the usage docs of this version, so that coding agents write markup the components accept: the rules the item templates enforce, the page skeleton of each area, and one reference page per component. Install it in a project with `npx skills add ./node_modules/@coveo/atomic/dist/skills/coveo-atomic`, or point your agent at that directory.
