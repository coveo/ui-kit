Add a hybrid Atomic + Headless commerce sample. Atomic Commerce drives the whole experience except the search box, which is replaced by a custom element built on Headless commerce controllers to combine query suggestions, recent searches, per-facet filter suggestions, and instant products in one grouped dropdown. Also demonstrates composing custom UI around an untouched Atomic facet, and documents when to customize, compose around, or replace an Atomic component.
