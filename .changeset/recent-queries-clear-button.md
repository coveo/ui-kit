Add the `with-clear-recent-button` property to `atomic-search-box` and `atomic-commerce-search-box`. When it is set, the option to clear recent queries is rendered as a "Clear recent searches" button below the suggestions instead of as the first suggestion, so the Down arrow key goes straight to the suggestions and the button is reached with the Tab key. The button can be styled with the new `recent-query-clear-button` part.
