This component defines how the `atomic-commerce-product-list` component displays Spotlight Content. It works like `atomic-product-template`, but for Spotlight Content.

Spotlight Content is only requested and displayed when the `enable-spotlight-content` attribute is set on the `atomic-commerce-interface` component. It's displayed in the `grid` and `list` displays, not in the `table` display.

A `template` element must be the child of an `atomic-spotlight-content-template`, and an `atomic-commerce-product-list` must be the parent of each `atomic-spotlight-content-template`.
* **Note:** Any `<script>` tags that are defined inside a `<template>` element will not be executed when the Spotlight Content is being rendered.

```html
<atomic-commerce-interface enable-spotlight-content>
  ...
  <atomic-commerce-product-list>
    <atomic-product-template>
      <template>
        <!-- How products are displayed -->
      </template>
    </atomic-product-template>

    <atomic-spotlight-content-template>
      <template>
        <atomic-product-image></atomic-product-image>
        <atomic-product-link class="font-bold"></atomic-product-link>
        <atomic-product-text field="description"></atomic-product-text>
      </template>
    </atomic-spotlight-content-template>
  </atomic-commerce-product-list>
</atomic-commerce-interface>
```

When no `atomic-spotlight-content-template` is defined, the product list uses a default template: a card tinted with the primary color that displays a "Spotlight" tag, the image (when the Spotlight Content has one), the name, and a "See more" link.

## Template components

Spotlight Content has its own fields: `id`, `clickUri`, `desktopImage`, `mobileImage`, `name`, `nameFontColor`, `description`, `descriptionFontColor` and `altText`. Inside an `atomic-spotlight-content-template`, use the following product template components, which adapt to Spotlight Content:

* [`atomic-product-link`](/docs/atomic-product-link--docs): links to the `clickUri`, displays the `name` by default, and logs Spotlight Content click analytics.
* [`atomic-product-image`](/docs/atomic-product-image--docs): displays the `desktopImage`, or the `mobileImage` on viewports narrower than the interface mobile breakpoint.
* [`atomic-product-text`](/docs/atomic-product-text--docs): displays a field such as `name` or `description`, using its configured font color.

Other product template components, such as `atomic-product-price` or `atomic-product-rating`, rely on product fields and aren't meant for Spotlight Content.

## Template Conditions

As with product templates, you can use `must-match-*` and `must-not-match-*` attributes to apply different templates to different Spotlight Content, based on their fields. The first template whose conditions are met is applied.

```html
<!-- Template for a specific Spotlight Content -->
<atomic-spotlight-content-template must-match-id="summer-sale">
  <template>
    <atomic-product-link>
      <atomic-product-image></atomic-product-image>
    </atomic-product-link>
  </template>
</atomic-spotlight-content-template>

<!-- Template for every other Spotlight Content -->
<atomic-spotlight-content-template>
  <template>
    <atomic-product-image></atomic-product-image>
    <atomic-product-link></atomic-product-link>
  </template>
</atomic-spotlight-content-template>
```

You can also set conditions programmatically with the `conditions` property:

```js
document.querySelector('#sale-template').conditions = [
  (spotlightContent) => /sale/i.test(spotlightContent.name),
];
```

## Grid link

In the `grid` display, clicking anywhere on a Spotlight Content item opens its link. To customize that link, add a `template` with `slot="link"` that contains a single `atomic-product-link`:

```html
<atomic-spotlight-content-template>
  <template>...</template>
  <template slot="link">
    <atomic-product-link>
      <a slot="attributes" target="_blank"></a>
    </atomic-product-link>
  </template>
</atomic-spotlight-content-template>
```

## Custom rendering

When using a framework that doesn't use plain HTML templates, use the `setSpotlightContentRenderFunction` method of `atomic-commerce-product-list`, the Spotlight Content equivalent of `setRenderFunction`.
