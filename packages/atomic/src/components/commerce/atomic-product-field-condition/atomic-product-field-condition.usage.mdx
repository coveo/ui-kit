
`atomic-product-field-condition` conditionally renders its content based on product attributes.
This component can verify whether specified fields are defined, not defined, match specific values, or do not match specific values.

It is typically used within `atomic-product-template`.

**Defined fields:** `if-defined` renders the content only when the product has every field it lists, and `if-not-defined` renders it only when the product has none of the fields it lists. Comma-separated field names in these two attributes represent a logical AND, unlike the comma-separated values of a `must-match-*` or `must-not-match-*` attribute, which represent a logical OR. For example, `if-defined="ec_brand,ec_rating"` means a product must have both an `ec_brand` and an `ec_rating`, while `if-not-defined="ec_brand,ec_rating"` means it must have neither. Field names are not trimmed, so don't put spaces after the commas: `if-defined="ec_brand, ec_rating"` looks for a field named `" ec_rating"`, with a leading space, and never matches.

```html
<atomic-product-template>
  ... 

  <atomic-product-field-condition
    if-defined="ec_name"
 
  >
  <span>Render me if <strong>ec_name</strong> is defined.</span>
  </atomic-product-field-condition>
  
</atomic-product-template>
```
