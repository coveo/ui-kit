You don't add this component to your page directly. The `atomic-commerce-product-list` component renders one `atomic-commerce-spotlight-content` for each Spotlight Content item returned by the Commerce API, at the position the API returned it.

To request and display Spotlight Content, set the `enable-spotlight-content` attribute on the `atomic-commerce-interface` component:

```html
<atomic-commerce-interface type="search" enable-spotlight-content>
  ...
  <atomic-layout-section section="products">
    <atomic-commerce-product-list display="grid"></atomic-commerce-product-list>
  </atomic-layout-section>
</atomic-commerce-interface>
```

Each Spotlight Content item renders as a link to its `clickUri`, with:

- The `desktopImage`, replaced by the `mobileImage` (when provided) on viewports narrower than the interface mobile breakpoint.
- The `name` and `description`, when provided, using the `nameFontColor` and `descriptionFontColor` values configured for the Spotlight Content.

Selecting a Spotlight Content item logs a Spotlight Content click analytics event, not a product click.

Spotlight Content isn't a product: `atomic-product-template` templates and product components (such as `atomic-product-link` or `atomic-product-price`) don't apply to it.

Spotlight Content is displayed in the `grid` and `list` displays of `atomic-commerce-product-list`. It isn't displayed in the `table` display.

### Styling

The product list exposes each Spotlight Content element as the `spotlight-content` part, and its inner parts with a `spotlight-content-` prefix. The `outline` and `result-list-grid-clickable-container` parts apply to every item in the list, products and Spotlight Content alike.

```css
atomic-commerce-product-list::part(spotlight-content) {
  background-color: var(--atomic-neutral-light);
}

atomic-commerce-product-list::part(spotlight-content-link) {
  border: 1px solid var(--atomic-neutral);
}

atomic-commerce-product-list::part(spotlight-content-name) {
  font-size: 1.25rem;
}
```
