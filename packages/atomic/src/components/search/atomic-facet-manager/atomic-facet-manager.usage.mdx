Place facets inside the `atomic-facet-manager` component within the "facets" section of your layout:

```html
<atomic-search-interface>
  ...
  <atomic-search-layout>
    <atomic-layout-section section="facets">
      <atomic-facet-manager collapse-facets-after="4">
        <atomic-facet field="author" label="Authors"></atomic-facet>
        <atomic-facet field="source" label="Source"></atomic-facet>
        <atomic-category-facet field="geographicalhierarchy" label="Geography"></atomic-category-facet>
        <atomic-numeric-facet field="ytviewcount" label="Views"></atomic-numeric-facet>
        <atomic-automatic-facet-generator desired-count="3"></atomic-automatic-facet-generator>
      </atomic-facet-manager>
    </atomic-layout-section>
  </atomic-search-layout>
</atomic-search-interface>
```

## Dynamic Navigation Experience (DNE)
The facet manager leverages Coveo's [Dynamic Navigation Experience](https://docs.coveo.com/en/3383) to automatically order facets based on their relevance to the current search query.
It also automatically selects facets to improve the user experience.

## Facets in popovers
A facet wrapped in an [`atomic-popover`](?path=/docs/atomic-popover--docs) is managed like any other facet. The popover moves along with its facet, so the facet always stays inside it.

```html
<atomic-layout-section section="horizontal-facets">
  <atomic-facet-manager>
    <atomic-popover>
      <atomic-facet field="author" label="Authors"></atomic-facet>
    </atomic-popover>
    <atomic-popover>
      <atomic-facet field="source" label="Source"></atomic-facet>
    </atomic-popover>
  </atomic-facet-manager>
</atomic-layout-section>
```

A popover always displays its facet expanded. For this reason, a facet inside a popover is never collapsed and does not count towards `collapse-facets-after`.
