
The `atomic-insight-smart-snippet-feedback-modal` component displays a modal dialog that allows users to provide feedback on a smart snippet answer. The `atomic-insight-smart-snippet` component automatically inserts it right before itself the first time the user dislikes the snippet or clicks its "Explain why" button, and removes it along with itself, so you typically do not need to add it manually.

```html
<atomic-insight-interface>
  <atomic-insight-smart-snippet></atomic-insight-smart-snippet>
</atomic-insight-interface>
```
